## 🇺🇸 English Version

Welcome to the official repository for **Evangelion Friday Impact**! 
This is a full-week FNF mod based on the legendary anime *Neon Genesis Evangelion*, fully developed by a solo developer.

### 🕹️ Features
- **Immersive Evangelion Universe:** Experience a dark, apocalyptic atmosphere inspired by the original anime.
- **Custom Soundtrack & Stages:** Play through original tracks with cinematic stage backgrounds and custom assets.
- **Unique Mechanics & Visuals:** Includes custom UI, scripting, and event cutscenes that bring the Eva universe to life.

### 🛠️ Credits
- **a01086523325-sudo** (Solo Developer)
  - Art / Animation
  - Coding / Scripting
  - Music Composing
  - Charting

### 📦 How to Install & Play
1. Go to the **Releases** section on the right side of this page.
2. Download the latest version zip file (e.g., `Evangelion_Friday_Impact_v1.0.0.zip`).
3. Extract the ZIP file anywhere on your PC.
4. Run the `.exe` file and enjoy the mod!
