## 🇺🇸 English Version

Welcome to the official repository for **Evangelion Friday Impact**! 
This is a full-week FNF mod based on the legendary anime *Neon Genesis Evangelion*, fully developed by a solo developer.

### 🕹️ Features
- **Immersive Evangelion Universe:** Experience a dark, apocalyptic atmosphere inspired by the original anime.
- **Custom Soundtrack & Stages:** Play through original tracks with cinematic stage backgrounds and custom assets.
- **Unique Mechanics & Visuals:** Includes custom UI, scripting, and event cutscenes that bring the Eva universe to life.

### 🛠️ Credits
- **a01086523325-sudo** (Solo Developer)
  - Art / Animation
  - Coding / Scripting
  - Music Composing
  - Charting

### 📦 How to Install & Play

1. Make sure you have **Friday Night Funkin' (Psych Engine 0.7.x or 1.0+)** installed.
2. Go to the **Releases** section on the right side of this page and download the latest zip file (e.g., `Evangelion_Friday_Impact_v1.0.0.zip`).
3. Extract the ZIP file and move the extracted folder into your Psych Engine's `mods/` directory.
4. Launch the game, go to the **Mods** menu, and make sure **Evangelion Friday Impact** is enabled.
5. Select the week in **Story Mode** or **Freeplay** and enjoy!

1. 먼저 **프라이데이 나이트 펑킨 (Psych Engine 0.7.x 또는 1.0 이상)**이 설치되어 있어야 합니다.
